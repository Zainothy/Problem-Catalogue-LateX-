# Templates

Each subdirectory is a complete, buildable figure.

Copy a template manually, or run:

```powershell
.\Figures\common\new-figure.ps1 -Category mechanics -Name new-name -Template standalone-tikz
```

Available templates:

- `standalone-tikz`
- `pgfplots-graph`
- `free-body-diagram`
- `euclidean-geometry`
- `topology`
- `commutative-diagram`
- `vector-diagram`
- `graph-theory`
- `coordinate-axes`
- `phase-portrait`
